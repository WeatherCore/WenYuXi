# 致我最亲爱的你 · 情书网站

一个送给她（他）的专属情书网站：柔光浪漫风、零依赖纯静态、开箱即用。
信封开场 → 扉页（在一起第 N 天）→ 情书 → 时光相册 → 我们的故事 → 想对你说 → 往后余生。

## 项目结构

```
情书/
├─ index.html                  主入口（情书原文直接写在里面，有"情书原文"注释标记）
├─ README.md                   本文件
└─ assets/
   ├─ css/
   │  ├─ base.css              变量 / 全局背景 / 氛围光 / 烫金 / 悬浮按钮
   │  ├─ envelope.css          开场信封
   │  ├─ sections.css          各章节版式（相册 / 时间轴 / 卡片墙 / 结尾）
   │  └─ animations.css        渐显系统 / 关键帧 / 减弱动态降级
   ├─ js/
   │  ├─ config.js             ★ 全站内容配置 —— 日常只需要改这一个文件
   │  ├─ particles.js          星光 + 花瓣粒子 / 鼠标柔光
   │  ├─ envelope.js           信封开启动画
   │  ├─ reveal.js             逐段渐显 / 章节圆点导航 / 回到顶部
   │  ├─ music.js              轻音乐（Web Audio 本地合成，默认关闭）
   │  └─ main.js               渲染配置内容并启动全站
   └─ img/photos/              相册照片（p1–p6.svg 是占位图，直接替换）
```

## 快速定制（三步换上你们的故事）

1. **纪念日**：打开 `assets/js/config.js`，把 `startDate` 改成你们在一起的日子（`YYYY-MM-DD`）。
2. **照片**：把真实照片放进 `assets/img/photos/`，再把 `config.js` 里 `gallery` 的 `src`
   改成对应文件名（如 `'assets/img/photos/我们.jpg'`），`caption` 写一句话说明；
   横版照片加 `wide: true`。照片还没准备也不影响，会自动显示优雅的占位图。
3. **回忆与情话**：改 `config.js` 里的 `timeline`（时间轴）和 `wishes`（卡片墙文案），
   条目数量不限，会自动排版。

改情书正文：直接编辑 `index.html`，搜索「情书原文」定位，保持 `<p>` 段落结构即可；
落款（`永远爱你的哥哥` / `写于某个想你至深的夜晚`）也在这一段里。

## 本地预览

无需构建、无需依赖，直接双击 `index.html` 就能在浏览器打开。
（想要更接近线上的效果，也可以在该目录跑任意静态服务器，如 `python -m http.server 8000`。）

## 部署上线

纯静态项目，任何静态托管都能直接用：

- **GitHub Pages**（仓库名 `WenYuXi`）：推送到仓库 → Settings → Pages → 选择分支根目录，
  稍等几分钟即可通过 `https://<用户名>.github.io/WenYuXi/` 访问。
- **任意服务器**：把整个文件夹上传到网站目录（Nginx / Apache 均可）。
- **对象存储 / OSS / COS**：开启静态网站托管，上传全部文件。
- **Vercel / Netlify / Cloudflare Pages**：导入该文件夹，无需配置框架。

> 唯一的外部依赖是字体（思源宋体 / 手写体走 CDN），加载失败会自动回退到系统衬线字体，页面不会坏。

## 设计约定

- 配色：奶白 / 淡香槟 / 浅玫瑰粉 / 雾紫 / 浅金，低饱和不刺眼
- 动效：逐段温柔淡入，花瓣星光缓慢飘落，禁止频闪、抖动、爆炸特效
- 音乐：右下角手动开关，默认关闭，本地合成无版权风险
- 无障碍：支持系统「减弱动态」，键盘可操作，对比度达标
